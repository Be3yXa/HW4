# Условие задачи
Чтобы получить философский камень, алхимик должен смешать три ингредиента в строгой пропорции. Реакция запустится, только если масса каждого ингредиента (A, B, C) кратна трем. Запишите условие успешного запуска реакции.

1. Начало
2. Объявить константы:
3. Задать исходные данные:
  * A - масса первого камня,
  * B - масса второго камня.
  * C - масса третьего камня.
4. Проверить массу каждого камня на кратность трём:
  * A % 3 == 0 && B % 3 == 0 && C % 3 == 0
5. Если каждая из масс кратна 3, выводим сообщение:
  * Реакция успешно запустилась! Философский камень получен.
6. В противном случае выводим сообщение:
  * Реакция не запустилась. Пропорции нарушены.
7. Конец

# 2. Реализация программы
~~~
#include <stdlib.h>
#include <stdio.h>
#include <locale.h>
int main() {
    setlocale(LC_ALL, "RUS");
    int A, B, C;

    printf("Введите массу ингредиентов A, B и C: ");
    scanf("%d %d %d", &A, &B, &C);

    if (A % 3 == 0 && B % 3 == 0 && C % 3 == 0) {
        printf("Реакция успешно запустилась! Философский камень получен.\n");
    }
    else {
        printf("Реакция не запустилась. Пропорции нарушены.\n");
    }

    return 0;
}
~~~
